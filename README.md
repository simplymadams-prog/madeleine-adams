# Madeleine Adams — Personal Website

A simple editorial portfolio site for Madeleine Adams.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Choose **Pages** under **Code and automation**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the **main** branch and **/(root)** folder.
5. Click **Save**.

GitHub will provide the public Pages address after deployment. The site files are index.html and style.css.
